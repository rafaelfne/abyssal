# Report Project Status

Read `AGENTS.md` and refresh current evidence from `origin/main`, issues, pull requests, milestones and the Abyssal MVP Project.

Reconcile sources before making numeric or completion claims. An issue label or Project column does not prove that work is active; require an assignee, explicit agent run or linked open pull request. A merged pull request and current `main` establish delivery.

Write in concise stakeholder language:

1. Human decisions and blockers requiring attention.
2. Outcomes currently in progress and their evidence.
3. Ready work that is queued but not running.
4. Recently delivered product value.
5. One recommended next action.

Include links and traceable counts. Separate product progress from repository activity and mention stale or contradictory metadata. Do not mutate project state.
